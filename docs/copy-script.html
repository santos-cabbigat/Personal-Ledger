Update your ledger app

  1. Open your ledger spreadsheet on a computer. Choose Extensions → Apps Script.
  2. Replace Code.gs with the complete script below, then save.

  3. In Project Settings, turn on Show “appsscript.json” manifest file in editor. Replace that file with the manifest below and save. It enables Google Drive and Google Sheets for the app.

  4. Choose Deploy → Manage deployments → Edit → New version → Deploy. Keep Execute as: User accessing the web app and use the existing deployment. Google may ask you to authorize the updated app.
