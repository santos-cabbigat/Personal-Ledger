Using the ledger

Personal Ledger helps you record transactions and prepare reports using the owner’s personal Supabase project. Use the confirmed email registered for this ledger.

Posting and sharing

Review the book, date, accounts, and amounts before posting. A posted entry changes the live database. A daily archive copies the journal revisions to the owner’s Google Sheet. The owner manages ledger membership and workbook sharing separately.

Reports and sample data

Reports reflect the entries and filters you select. Check the selected period, book, and entry status before relying on a total or sending an export. The sample ledger is for exploring the interface and uses example transactions.
